# Proyek Font Moringa

Ini adalah muka huruf (*typeface* / *font*) yang didesain untuk materi publikasi oleh Humas MAN Lumajang dan club D'Graph.

Masih dalam tahap beta.

## Kekurangan *Font* Ini

* Belum ada *kerning* untuk menyesuaikan jarak huruf ke huruf
* Hanya untuk bahasa Inggris, Indonesia dan Melayu (dalam kata lain, hanya memiliki 95 karakter dasar ASCII)
* Hanya tersedia varian biasa dan tebal untuk saat ini 
* Bentuk beberapa karakter mungkin kurang pas 

## Lisensi *Font* Ini

*Font* ini tersedia di bawah ketentuan lisensi *SIL Open Font Licence*.
